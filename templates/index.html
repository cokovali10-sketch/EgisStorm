История проверок

    Ничего не хранится на сервере.

    Email по утечкам

    Проверь, был ли твой адрес в известных утечках (HaveIBeenPwned).

    Проверка пароля

    Сколько раз пароль встречался в утечках + оценка силы (Pwned Passwords).

    Генератор паролей

    Криптостойкие пароли через Python secrets.

    DNS записи

    Пассивный просмотр A, AAAA, NS, MX, TXT, CNAME записей домена.

    WHOIS / RDAP

    Регистратор, даты, статусы и NS из публичного реестра RDAP.

    Информация по IP

    Гео, ASN, провайдер, reverse DNS. Только публичные данные сети.

    SSL сертификат

    Издатель, срок действия, SAN, TLS-версия и шифр удалённого хоста.

    Security headers

    Аудит заголовков безопасности сайта (HSTS, CSP, X-Frame-Options и др.).

    Хеширование

    MD5 / SHA-1 / SHA-2 / SHA-3 + определение алгоритма по длине.

    Base64

    Кодирование / декодирование.

    JWT декодер

    Разбор header/payload, проверка alg=none, exp, nbf.

    Анализатор URL

    Индикаторы фишинга: HTTPS, IP-хост, punycode, короткие ссылки, TLD.

    Владелец IP

    Кому принадлежит адрес: организация, страна, диапазон сети (RDAP).

    Subnet / CIDR

    Калькулятор подсети: диапазон, маска, broadcast, число хостов.

    Проверка MX

    Есть ли почтовые сервера у домена и не одноразовый ли это email (анти-фишинг).

    Развёртка ссылки

    Показывает цепочку редиректов короткой ссылки до конечного URL.

    Поиск CVE

    Уязвимости по названию продукта/версии (база CVE через NVD).

    Мой IP

    Твой внешний адрес, гео и провайдер — только твои данные.

    TCP порт

    Открыт ли порт на хосте + проверка общих сервисов (для своей инфраструктуры).

    robots.txt

    Просмотр правил robots.txt сайта: какие разделы запрещены и sitemap.

    Шифрование AES

    Образовательный инструмент: AES-256-CBC + PKCS7. Ключ выводится из пароля (SHA-256).

    2FA / TOTP

    Генерация секрета и QR для Google Authenticator / Aegis.

    WireGuard VPN

    Генератор клиентского конфига и Curve25519 ключей для вашего сервера.
